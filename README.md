2024. 06. 24 - 07. 05
         
프론트엔드 : 4명
백엔드: 4명


## 📍 프로젝트 요약

MLB 쇼핑몰의 **프론트엔드 클론 코딩 프로젝트**로, 백엔드 개발팀과의 **첫 협업 프로젝트**입니다. 쇼핑몰의 주요 기능을 구현하여 실제 웹사이트와 유사한 사용자 경험을 제공하는 것을 목표로 했습니다.

## 사용 스택 

React.js, Redux-Tookit 

## 주요 기능

- 회원 가입, 로그인, 로그아웃, 회원 탈퇴
- 전체/카테고리별 물품 조회
- 물품 상세 조회 및 장바구니 추가
- 장바구니 조회, 수정, 삭제
- 장바구니 내 물품 결제 상태 전환 (실제 결제 미포함)
- 판매 물품 등록 및 조회/수정
- 주문 내역 조회

## 📍 기여 - 최정민 

- **회원 가입**, **로그인**, **로그아웃** (각 입력 필드에 **유효성 검사** 추가)
- **회원 탈퇴** 
- 장바구니 **조회/수정/삭제** UI/UX
- 판매 물품 **조회** UI/UX
- 결제 완료 후 **성공 페이지 UI** 개발
